# Suporte

Para relatar erro, referência incorreta, comportamento inseguro, problema de instalação ou dúvida sobre o plugin, abra uma issue no repositório:

https://github.com/sbfrogerio/andreza-nutrition-professional-plugin/issues

Não publique dados de pacientes, prontuários, exames identificáveis, contatos, credenciais ou chaves de API. Um relato adequado contém apenas versão do plugin, ambiente utilizado, prompt desidentificado, comportamento observado e comportamento esperado.

Este canal não oferece atendimento médico ou emergencial.
