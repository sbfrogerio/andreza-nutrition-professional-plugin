# Andreza Nutrition Professional

Plugin de apoio técnico para nutricionistas, com foco em nutrição esportiva, endurance, acompanhamento clínico responsável e prática baseada em evidências.

O pacote reúne 21 skills para avaliação de atletas, diário alimentar, exames, histórico de treinos, recuperação, hidratação, periodização, logística de prova, suplementos, triagem RED-S e pesquisa científica.

## Segurança clínica

O plugin não diagnostica, não prescreve ou altera medicamentos e não decide aptidão esportiva. Suas saídas exigem revisão por profissional habilitado. Exames, suplementos e RED-S possuem barreiras de ativação expressa e critérios de encaminhamento.

## Instalação pelo marketplace do workspace

Administradores podem importar este repositório como marketplace GitHub em **Administração → Plugins → Adicionar → Importar marketplace**. Use a URL do repositório e deixe o caminho vazio.

Após a importação e disponibilização administrativa, membros encontram **Andreza Nutrition Professional** pela pesquisa da aba Plugins no ChatGPT e no Codex.
