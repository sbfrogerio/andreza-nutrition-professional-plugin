# Protocolo de ata a partir de transcrição

## Fonte principal

Usar a transcrição bruta integral. Notas complementares podem esclarecer metadados, mas não devem alterar silenciosamente o que foi dito.

## Tratamento da transcrição

- Preservar ordem e autoria.
- Corrigir apenas repetição, hesitação e erro evidente de reconhecimento quando o sentido for inequívoco.
- Marcar `[INAUDÍVEL]` para trecho sem recuperação.
- Marcar `[NÃO IDENTIFICADO]` para interlocutor incerto.
- Marcar `[A CONFIRMAR]` para data, valor, nome ou decisão ambígua.
- Não reconstruir frase a partir de contexto provável.

## Taxonomia

- **Relato:** informação apresentada pelo paciente ou terceiro.
- **Dado objetivo mencionado:** número ou documento citado, com fonte indicada quando conhecida.
- **Orientação:** conduta efetivamente comunicada pelo nutricionista.
- **Decisão:** item expressamente confirmado.
- **Alternativa discutida:** possibilidade sem confirmação.
- **Pendência:** ação futura; registrar responsável e prazo somente se ditos.

## Conciliação

Se transcrição e nota complementar divergem, registrar a divergência. A ata deve permitir conferência rápida contra o original.
