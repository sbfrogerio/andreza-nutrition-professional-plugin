# Matriz de roteamento

| Necessidade principal | Skill | Pré-requisito material |
|---|---|---|
| Consolidar avaliação | `nutri-avaliar-atleta` | anamnese/fontes identificadas |
| Registrar consulta | `nutri-redigir-ata-atendimento` | transcrição/notas cronológicas |
| Examinar ingestão | `nutri-analisar-diario-alimentar` | diário/recordatório/fotos |
| Comparar exames | `nutri-analisar-exames` | laudos originais e pedido explícito |
| Avaliar ciclos de treino | `nutri-analisar-historico-treinos` | sessões históricas |
| Resumir recuperação atual | `nutri-monitorar-recuperacao` | série recente com fonte/unidade |
| Comparar estratégias anteriores | `nutri-auditar-planos-anteriores` | planos e adesão/desfechos |
| Auditar produto/antidopagem | `nutri-auditar-suplementos` | rótulo/lote/lista vigente e pedido explícito |
| Triar RED-S | `nutri-triar-reds` | pedido explícito e fonte vigente |
| Criar periodização | `nutri-planejar-periodizacao` | microciclo e metas aprovadas |
| Planejar prova/hidratação | `nutri-planejar-hidratacao-prova` | teste válido e parâmetros aprovados |
| Operacionalizar viagem/evento | `nutri-planejar-logistica` | estratégia aprovada e logística |
| Atualizar evidência | `nutri-vigiar-evidencias` | pergunta estruturada |

Use as skills externas de literatura somente dentro do protocolo de `nutri-vigiar-evidencias` ou quando o usuário pedir diretamente a função correspondente.
